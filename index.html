I build machine-learning systems and the tooling around them, and I judge them by measurement: a result counts only after it survives re-validation against a baseline. This page is a short, factual index of that work.

Projects

  • Shogi NNUE evaluation port (YaneuraOu). Ported an NNUE evaluation function and verified it against the reference implementation: evaluation values matched exactly on 9,112 positions, at 2–3× the reference NPS. Version 6, trained on 41.41M positions, scored 189 wins / 111 losses (63.0%) against version 5.
  • Horse-racing prediction ML — a verification study. Compared 8 methods across 109 configurations. An apparent 101.2% return did not survive re-validation: over 354 fresh races it fell to 62.8%, below the 70.2% baseline, so the model was rejected as overfitted and not deployed. The negative result is the deliverable.
  • Voice-synthesis data and evaluation pipeline. Built a training corpus of 6,989 lines (7.08 hours) and an evaluation workflow based on ASR word-error measurement and model-merging experiments. Only the code and method are published; no voice data or trained voice models.
  • Climate simulation pipeline. A pipeline around NeuralGCM that turns climate-model output into terrain, population and historical-simulation inputs for a fictional-world simulation project, with an iterate-and-correct loop against the computed results.
  • Rendering and video tooling. Customised Remotion / Skia rendering pipelines (12-thread parallel drawing) and automated overnight build-and-edit queues for video work on a local GPU machine (RTX 5060 Ti).
